# 验证与运行

| 层级 | 必须覆盖 |
|---|---|
| 领域 | 非法状态、重复操作、暂停计时、超时不完成、等待释放个人时间 |
| 排程 | 固定/保护/活动块、依赖、资源、最小块、跨日/夏令时、过载 |
| 接口/存储 | 版本冲突、原子提案、幂等、重启恢复、撤销设备 |
| 界面 | 空/加载/错/离线、360/390px、键盘、减少动画、中文输入保留 |
| OPPO | 通知/精确提醒权限、锁屏、省电、划走、强停、重启、更新旧提醒 |
| 同步 | 移动网络、电脑断开、重放、双端离线冲突、计划回执 |
| 归档 | 正确用户日期、重试、来源/版本、备份恢复 |

浏览器验证不代表原生通知验证通过。ColorOS 17 的实际表现以本机测试为准。

## 凭证和数据

只管理录入的任务、执行和反馈。模型接收当前请求必要片段；实验信息可只传摘要或不发送。原文保留，推测标注来源。

Key 仅电脑端；配对用短期一次性码、电脑确认与可撤销设备凭证。日志去除密钥/配对码/敏感正文。监听和防火墙范围按部署实际需要设置。

## 恢复与部署

启动检查未完成作业与迁移版本；归档原子写入；计划改动在手机回执前显示待同步。先本地、再双端、最后自启动。迁移前备份，程序回滚核对数据兼容；应用签名身份持续保管。

首次使用：时区/作息 → 配对 → 通知与必要提醒许可 → 测试提醒 → 移动网络同步 → 一个真实任务。

每次验证记录日期、设备/版本、步骤、实际表现和限制。未执行不打勾。草图检查放在 `docs/prototype-review.md`。
