# 范围与验收

| ID | 用户能力 | 可观察验收 |
|---|---|---|
| R01 | 创建结果明确的任务 | 标题、完成标准、预计投入必填；项目/截止/依赖可选；可更新剩余投入 |
| R02 | 七天课表 | 切周、手机横滑切日、选择时段；拖动及明确的时间表单均可改期 |
| R03 | 固定和弹性安排 | 自动排程保护预约及作息；保存拒绝个人时间/资源冲突 |
| R04 | 今日卡片和列表 | 当前、下一项、待反馈可见；卡片可键盘操作；完整列表可读 |
| R05 | 一次执行 | 开始/暂停/恢复/结束；剔除暂停投入；重启后重建；在线仅一段活动执行 |
| R06 | 本地开始/结束提醒 | 已同步计划由手机调度；权限异常与同步过期可见；到点不自动完成 |
| R07 | 快捷反馈 | 完成/部分/等待/打断/未开始；未回复保持待确认；允许补填 |
| R08 | 弹性重排 | 迟到/超时/插入任务生成预览；保留固定/保护/依赖/最小块；历史不覆盖 |
| R09 | 自然语言助手 | 结构化提案校验后执行；只补问必要字段；无模型时手动流程可用 |
| R10 | 日终回顾 | 两三句结合日志生成可编辑摘要；未提及的任务不擅自完成 |
| R11 | 跨设备 | 缓存可用、离线操作排队、重放幂等、并发冲突显式处理 |
| R12 | 电脑归档 | Markdown + 结构化数据；失败重试；报告版本可追溯 |

## 反馈负担

每段默认一次点选，必要时选择剩余时长。结束提醒一次，10 分钟后至多补提醒一次（可配置）；安静时段保留待反馈。每天文字合计两三句话。

## 最小可用切片

任务 → 单段安排 → 主动开始 → 结束反馈 → 剩余工作。完整 V1 再覆盖周课表、规则重排、通知、同步、对话和归档。

## 范围边界

先服务一人两台设备，不建设团队协作、公开平台、第三方账号日历聚合或复杂求解器。真实实验自动采集需按程序另行定义；V1 用户说明与附件索引即可。

## 过载处理

显示冲突原因、影响项和未安排余量。用户可减少范围或延期。固定预约、用餐/睡眠等保护块只允许显式编辑；不为清空任务而持续挤占全天。
