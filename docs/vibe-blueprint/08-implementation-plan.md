## 微信入口的接续顺序

用户已选择「电脑微信小号 ↔ 手机大号」普通好友私聊。先完成 W1 小号必要控件/身份核验与 W2 单会话收发、锁屏、重复消息和重启矩阵，再落定具体依赖；随后实施 W3 持久队列与权限边界、W4 对话拟办及反馈、W5 主动提醒与日报、W6 隔夜和一周试用。分阶段验收详见技术路线 §6–7。

现有业务测试不能作为微信验收证据。电脑后台与 App 保持同一数据源，新增通道的所有业务修改继续走已有领域操作；单靠接入聊天框不能替代服务器消息调度与 AI 日报开发。
