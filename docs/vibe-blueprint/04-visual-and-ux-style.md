# 视觉与交互

建议安静、有秩序的个人工作台：暖白纸面、墨绿文字、细线与适量留白。突出当前任务和结果标准。

## 视觉标记

- 背景 #f5f4ef，面板 #ffffff，文字 #20382e，次文字 #647068，主操作 #245a43。
- 秋招土橙、代码深绿、Fab 蓝灰；项目用文字和颜色共同表达。
- 中文使用本机微软雅黑，时间数字配 Georgia；草图不加载外部字体。
- 8px 间距基准；16–24px 圆角；细边线优于强阴影。

## 卡片和课表

当前卡片完整显示时间、项目、标题、结果和操作；邻近卡片缩小并稍降对比。模糊只用于装饰内容，不能妨碍操作。提供前后按钮、回到当前、普通列表。

桌面七天同屏；手机日期横滑、单日视图。固定预约明确标记。拖动之外提供时间表单，保证键盘可用。

## 可达性

- 触控目标至少 44px；焦点可见，颜色不独立表达状态，正文对比目标 4.5:1。
- 模态框有标题、初始焦点、Esc 关闭和焦点恢复。
- 减少动画模式关闭过渡。
- 检查 360/390px 和桌面；无横向溢出；键盘出现仍可提交。

文案具体中性，例如「还需要多久」「下一步是什么」「今天还有这些任务未确认」。计时与结果分开展示。
