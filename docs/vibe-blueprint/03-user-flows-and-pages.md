# 页面和流程

| 页面 | 电脑 | 手机 | 主要动作 |
|---|---|---|---|
| 今日 | 导航 + 当前任务/列表 + 摘要 | 卡片 + 列表 + 底部导航 | 开始、暂停、反馈 |
| 周课表 | 七天与时间轴 | 日期条 + 单日，横滑切日 | 新建、详情、改期 |
| 助手 | 对话和变更预览 | 对话、展开预览 | 描述、确认/取消 |
| 回顾 | 记录、两三句输入、归档状态 | 顺序纵向排列 | 修正、保存、历史 |
| 项目/详情 | 筛选与抽屉 | 全屏详情 | 标准、依赖、余量、检查点 |
| 设置 | 设置面板 | 设置页 | 作息、时区、配对、权限、连接 |

草图重点覆盖今日、周课表、助手和回顾。真实连接/权限配置在原生切片中实现。

## 关键流程

1. 新建：描述任务 → 确认结果标准/投入 → 检查约束 → 时间块 → 提醒 → 用户点击开始，记录实际时间。
2. 等待：到点待反馈 → 等待结果 → 填检查时间和下一步 → 结束本次投入 → 释放个人时间 → 检查点查看结果。
3. 重排：部分完成 → 剩余投入 → 完整变更预览（含未安排余量） → 确认/取消 → 保存新版本 → 更新提醒。
4. 日终：查看实际记录 → 两三句话 → 事实与建议分开 → 修正 → 保存归档；模型故障先保留原文。

## 状态处理

- 空日程引导安排一个结果和一段时间；加载保留缓存和更新时间。
- 离线显示最后同步与待传数量，本地执行和反馈继续。
- 权限未授权显示设置入口与影响；不谎称提醒启用。
- 出错保留输入、提供重试；提交防重复。
- 双端离线同时开始不同任务：保留双方事实，恢复后标记冲突，用户校正重叠。
- 跨午夜/夏令时按 IANA 时区解释；有歧义或不存在的本地时间显式选择。

## 草图体验路线

切换今日卡片 → 开始/结束 → 部分完成 → 查看重排 → 应用 → 周课表查看固定 Fab → 回顾保存 → 手机预览切日。全部为内存演示，刷新恢复。
