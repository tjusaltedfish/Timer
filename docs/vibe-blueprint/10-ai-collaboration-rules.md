# 后续 AI 协作规则

先读 00-index、02-scope-and-requirements 和当前任务相关契约。默认建议不能写成用户已明确确认的事实。

## 当前授权阶段

用户当前持续目标为「完成一版手机+电脑的初版」，已进入正式实现。允许在目标内继续编码、测试和配置项目独立工具链。接受新 SDK 许可、付费模型调用、公开发布等事项仍以明确授权为准。真实进度见 docs/STATUS.md；不得把原型或后台单测等同于双端交付。

## 工作方式

- 一次一个可验证切片；汇报改变、验证和真实限制。
- 已授权的局部实现/修复继续推进，不重复请求许可。
- 安装系统组件、新增费用、公开访问或产品方向变化时说明具体范围；有充分现有授权则继续。
- 范围/契约变化同步蓝图和决策记录。
- 工具链缺失先记录与补齐，不擅自换框架。
- 只有用户或适用规则明确要求才启动子代理。

## 领域原则

任务、计划和实际执行分开；沉默或到点不推定完成。重排只调整未来；真实记录可追溯。演示数据、模型建议、用户确认分别标识。自动修改尊重硬约束。

## 验证

当前草图用浏览器检查主要流程和手机布局；后续 server 使用独立环境 pytest，Flutter 使用 analyze/test，通知与后台必须 OPPO 真机验证。只报告真正执行的检查，秘密不进入输出。

时区使用客户端或应用明确设置，初始 America/Los_Angeles。中文项目文档和用户反馈为默认。
