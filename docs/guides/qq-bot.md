# QQ 助手接入：需要你本人完成的步骤

适用：**QQ 官方机器人（WebSocket 长连接）**路线。代码在 `server/app/qq.py`，接口契约见 `docs/qqbot-c2c-api-spec.md`，公众号那条老路仍在（`docs/guides/wechat-test-account.md`），两条通道可以同时开着。

## 为什么换成 QQ

| | 公众号测试号 | QQ 官方机器人 |
|---|---|---|
| 公网依赖 | 需要域名 + Cloudflare 隧道，回调必须 443 | 不需要。电脑的后台**主动往外**连 QQ 的 WebSocket |
| 头像 | 改不了 | 在开放平台能换 |
| 置顶 / 聊天入口 | 消息界面深，进不去 | 跟普通好友一样在会话列表，可置顶 |
| 人格与闲聊 | 只能干活 | 同一个人格，既能干活也能聊 |
| 主动消息 | 48 小时窗口外只能发模板消息 | 单聊主动消息 1000 条/人/天（用户侧要允许） |

隧道仍然保留——手机的同步和安装包下载走的就是它；QQ 只是不再需要它。

## 一、创建机器人（只能你本人操作）

1. 浏览器打开 <https://q.qq.com/>，用 QQ 登录，进开发者中心，创建机器人（个人主体选「个人开发者」即可，不用企业资质）。
2. 填名字、头像、简介，提交。名字和头像这里就能改，不用等审核通过再改。
3. 进「开发设置」拿两串东西：
   - **AppID**：纯数字。
   - **AppSecret**：点查看/重置后复制，**只显示一次**。别发到聊天里，直接填进瞬时。
4. **不要填 IP 白名单**：家宽 IP 会变，填了反而把自己锁在外面。白名单只影响 OpenAPI，不影响机器人默认行为。
5. 「开发体验用户号码」最多 20 个。如果你打算用别人的号（或另一个小号）跟它聊，先把那个 QQ 号加进去；开发者本人的号可以直接在开放平台点「扫码聊天」。

## 二、填进瞬时的电脑端

电脑上打开瞬时 →「设置 · QQ 机器人」：

1. 填 AppID、AppSecret，点保存。保存后面板显示「已配置」。
2. AppSecret 存在 `%USERPROFILE%\TimePlanner\data\secrets\qq-secret`，只在电脑上，不进 Git、不下发手机、不打日志。
3. 电脑要开着瞬时（或后台在跑）才会连 QQ；关掉窗口后台还在跑。

## 三、绑定（谁发码谁绑定）

1. 设置页点「生成绑定码」→ 显示 6 位数字，10 分钟内有效。
2. 在 QQ 里找到这个机器人：开放平台页面上的「扫码聊天」，或者 QQ 里搜机器人名字。
3. 给它发这 6 位数字。它回「绑定好了」就完成了。之后**只回应这个号**，别人发消息会被静默丢掉。

## 四、验证

设置页点「发一条测试消息」，QQ 几秒内应该收到。设置页底部的队列会显示每条的状态：排队中 / 发送中 / 已发出 / 没发出去 / 不确定是否送达 / 已过期。

- 「没发出去」会把错误原因写在下面（例如用户关了主动消息）。
- 「不确定是否送达」表示发送时网络断了，QQ 可能已收到——为了防止重复，**这条永远不会自动重发**。

## 五、绑定之后怎么用

跟公众号里那套话完全一样（同一套指令，`server/app/chat_commands.py`）：

- 「今天」「帮助」「记忆」
- 「明晚八点学两小时算法」→ 回【拟办 XXXX】→ 回「确认 XXXX」才真的改日程，「不必 XXXX」放下
- 「完成了」「再给我 15 分钟」「提前」「撤销 XXXX」「今日总结：……」
- 到点提醒、日终复盘、周日简报在绑定后也会发到 QQ（设置里「到点提醒发到 QQ」开着才发）

人格是「大肥鱼」：日程上干脆准确，闲聊时能正常聊两句，不硬塞日程动作。

## 六、必须知道的限制

- **电脑关机或后台没运行时，QQ 里收不到任何回复**。机器人不是云端的，它就是你电脑上的后台。
- **主动消息有三重闸门**：① 你在 QQ 客户端设置里必须允许它主动发（关掉后必失败，错误码 40054013）；② 得先加过好友/有过互动；③ 配额 1000 条/人/天、单关系 20 条/分钟、机器人整体约 10 条/秒。到点提醒这种量级完全够用。
- **被动回复**：你刚说完话时的回复，在 60 分钟内有效、同一条消息最多回 4 次。长回复会被拆成几段发，瞬时把回复控制在几段以内。
- **群聊暂不支持**：单聊和群聊的文件接口不互通，而且你之前说暂时不开群聊。
- **表情包/图片暂未实现**：QQ 发图要先上传拿 `file_info` 再用富媒体消息类型发，这一版只发文字。
- **私聊界面有的客户端不显示机器人头像**（官方解释是宽屏消息展示），换了头像不一定看得到。

## 七、出问题先看哪里

- 日志：`%USERPROFILE%\TimePlanner\logs`（后台）——断线重连、发送失败都在这里。
- 机器人连不上：多半是 AppSecret 错（100016）或 AppID 无效（100007）；token 失效（11243）后台会自动重取，连续失败按 5 秒起指数退避到最多 120 秒重连一次。
- 发消息不回：先确认绑定了、后台在跑（浏览器打开 <http://127.0.0.1:8787/health>）。
- 关掉了「允许接收主动消息」：定时提醒会失败，被动回复仍然正常。

## 八、以后想换成自己的小号

QQ 官方机器人不管你是谁，身份都是「机器人」，不在好友列表里，也没法用它自己的号发消息。要用真实小号（显示成好友、能主动找你说话），得走第三方协议端路线（NapCat/SnowLuma + OneBot v11）。那条路的问题是小号被腾讯判定风险会被杀（连同绑定一起没）。代码上两条路是并列的通道实现，将来加 NapCat 只需要再写一个 `channels.py` 里的适配器，指令大脑和人格不用动。
