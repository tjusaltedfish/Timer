# 日终复盘与知识回忆（设计与实现边界）

日期：2026-10-19。状态：**设计已确认；1.1.0+3 已实现材料与原文复盘第一阶段，回忆卡片及间隔复习仍待实现**。

## 1.1.0+3 已实现范围

回顾页可手动选择文件、填写材料说明与两三句原文，生成复盘并归档。支持文本 PDF、DOCX 和常见文本/代码文件；可选择仅说明进入模型。日终自动作业使用已保存的当日原文与材料，有失败退避与调用上限。复盘与近期材料摘要可供同一助手使用；不自动写成用户长期偏好。

详细限制、调用与隐私选项、自动作业和验收见 [助手机制 §5](assistant-behavior.md)。以下仍包含目标设计：目录级不外发策略、长文深度检索、知识卡片、评分与间隔复习尚未实现。手机和电脑都能手动上传文件，此用户流程已替代下文“只在电脑选材”的早期限制。

## 要解决的事

用户的原话：在电脑上选好今天学了什么（自己保存的笔记）、这次的分析报告在哪里；AI 不只帮着总结复盘，还要帮着**回忆学过的知识点**。

拆成三件互相衔接的事：

1. **收集**：今天的材料在哪里——笔记、报告、代码、论文。
2. **复盘**：结合当天的日程、执行反馈、睡眠和材料，写一份当天的复盘，存档到电脑。
3. **回忆**：从材料里提炼知识点，之后按遗忘曲线，在接下来几天把它们一条条“问”回给你。

## 一天结束时的流程（电脑端）

```
回顾页 ──► ① 今天的材料
             · 手动添加：选择文件 / 文件夹 / 粘贴一段文字（用户决定：不自动扫描目录）
             · 每个材料可加一句话：「这是今天跑的刻蚀参数分析」
        ──► ② 你的两三句话（已有）
        ──► ③ 生成复盘（一次模型调用 + 每份材料各一次）
             · 今天的安排 vs 实际（已有数据，确定性统计）
             · 每份材料：三到五个要点 + 一句「和你的目标有什么关系」
             · 今天最值得注意的一个模式；明天的第一件事（拟办，可一键安排）
             · 回忆卡片草稿：每份材料 3–8 张
        ──► ④ 你看一遍卡片：保留 / 改写 / 删掉 → 存入卡片库
        ──► ⑤ 归档：archives/2026-10-19.md（复盘全文 + 材料清单 + 卡片）
```

手机端：可以看复盘，可以做回忆；**选材料只在电脑上**（文件都在电脑上）。

## 回忆（知识点复习）

- 每张卡片：一个问题、一个参考答案、出处（哪份材料、第几页/哪一节）。
- 题型优先「主动回忆」：问题要你自己说出来，不是选择题。例如：
  - 「ICP 刻蚀里提高 RF 偏压，对侧壁角度的影响是什么？为什么？」
  - 「快速排序最坏情况的复杂度，什么输入会触发？」
- 复习方式：先看问题 → 在心里或输入框里回答 → 翻开参考答案 → 自评「忘了 / 模糊 / 记得」。
- 间隔：按自评安排下次出现时间（1 天、3 天、7 天、16 天…，忘了就回到明天）。算法用成熟的间隔重复（SM-2 或其简化版），不自创。
- 入口：今日页一个安静的条目「今天有 6 张卡片等你回忆」；也可以在助手里说「考考我昨天学的刻蚀」。
- 写下自己的回答，AI 对照参考答案指出漏掉或说错的点，再给出建议评分（用户可改），按评分安排下次复习。

## 技术方案

| 部分 | 做法 |
|---|---|
| 材料读取 | 只在电脑后台读取，只读、不改、不移动文件。Markdown/TXT 直接读；PDF 用 `pypdf` 抽文字；Word 用 `python-docx`；代码文件直接读。图片和扫描件第一版不支持 |
| 不外发文件夹 | 设置里登记「不外发」文件夹；从这些文件夹选的文件只发送用户写的一句说明，不发原文 |
| 大文件 | 按章节/页切块，每块限长；超长材料先让模型做分块摘要再汇总；单次复盘设置费用上限 |
| 存储 | 新表 `materials`（路径、内容哈希、摘要）、`cards`（问题、答案、出处、下次复习时间、间隔、熟练度）、`card_reviews`（每次自评）。卡片走操作日志，手机端可离线复习，联网后同步 |
| 模型调用 | 沿用已经做好的助手通道（OpenAI 兼容接口，Key 只在电脑上），输出严格 JSON，生成的卡片也先是「草稿」，用户确认后才进卡片库 |
| 归档 | `archives/YYYY-MM-DD.md` 增加「材料」「要点」「回忆卡片」三节；同时保存 JSON 便于以后检索 |

## 隐私（需要用户明确同意）

材料内容会**发送给你配置的模型服务**（OpenAI 中转站或 DeepSeek）。实验数据、未发表的结果可能不适合外发。方案里预留：

- 每份材料可以标「只发我的笔记，不发原文」；
- 文件夹级别的「不外发」名单；
- 复盘前显示「这次会发送 N 份材料、约 X 字」。

## 用户决定（2026-10-19）

1. 材料来源：**每天手动挑文件**（文件 / 文件夹 / 粘贴文字），不自动扫描目录。
2. 第一版类型：**Markdown/TXT、PDF、Word、代码文件**全部支持；图片和扫描版 PDF 暂不支持。
3. 回忆方式：**卡片 + 写下回答让 AI 批改**，再按遗忘曲线安排下次复习。
4. 外发边界：**默认发送原文，可按文件夹排除**；每次复盘前显示将发送的份数与字数。
