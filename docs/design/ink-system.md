# 黑白简约水墨

用户于 2026-10-19 明确指定本方向，作为当前视觉标准。

- 纯灰阶：明亮纸面、浓淡墨色、灰阶项目笔触。印章、时间线、选中标记和问询使用焦墨及文字状态。
- 浅色纸面 `#F5F5F5`，卡片 `#FDFDFD`；标题 `#1C1C1C`，正文 `#333333`，辅助正文 `#5E5E5E`。
- 夜墨纸面 `#151515`，卡片 `#1D1D1D`；标题 `#ECECEC`，正文 `#D4D4D4`，辅助正文 `#A3A3A3`。
- 颜色集中在 `apps/planner/lib/theme/tokens.dart`；`ink_ui_test.dart` 验证所有色板及项目标记为灰阶，正文对比度 ≥4.5:1。
- 标题与时间使用本地文楷，正文使用系统字体；6px 卡片圆角、细墨线、轻纸纹，无阴影。
- 卡片轮盘按时间顺序排列，远离焦点时渐淡、缩小并轻微虚化。低矮窗口自适应卡片高度，焦点操作区固定可见；减少动画时关闭模糊、缩放和纸纹。
- 手机五项导航，设置从页头进入；桌面窄栏和今日时间轴。表单在手机显示为适应键盘的底部弹层。
