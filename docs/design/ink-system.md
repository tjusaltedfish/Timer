# 墨晕白纸（视觉规范 v3）

2026-10-19 用户反馈上一版「过于锐利、不够暖心」，要的是「墨水在纯白色画纸上晕染开」。本版替代此前的灰阶细线方案，仍保持黑白。

## 气质

- 纯白画纸，几团淡墨从页面角落化开；卡片像压在纸上的另一张纸，边缘被墨晕托起，而不是被细线框住。
- 圆、软、慢：大圆角，柔和光晕，动效慢入快稳。
- 文案温和：问候、「一件一件来」「留点时间给自己」，不催促、不说教。

## 颜色（`apps/planner/lib/theme/tokens.dart`）

- 纸：`#FFFFFF`；墨色是带一点松烟暖意的近中性灰，三通道差 ≤ 6（测试强制）。
- 焦墨 `#23211F` 标题 / 浓墨 `#3A3734` 正文 / 重墨 `#625F5C` 次要正文（对白纸约 6:1） / 淡墨 `#8D8B87` 仅装饰。
- 分类标记：四种深浅的墨灰，按用户自己建立分类的先后循环分配；分类不再内置。
- 深色模式「夜墨」同样规则，测试覆盖对比度 ≥ 4.5:1。

## 墨晕（`widgets/ink_bloom.dart`）

- 每团墨晕 = 4 层带噪声边缘的径向渐变 + 一圈更深的「水痕」+ 几缕沿纸纤维渗开的细晕，固定随机种子，可复现。
- 页面背景：右上一大团、左下一团，静态绘制在 `RepaintBoundary` 里，不随计时刷新。
- 焦点卡：背后的墨晕在获得焦点时 680ms 内「化开」（`SpreadingBloom`）。
- 减少动画时：不播放化开动画，不叠纸纹。

## 形状与层次

- 卡片圆角 22，弹层 26，控件 14；浅色模式不用描边，靠双层柔光晕（`InkPalette.halo`）。
- 主按钮焦墨实心；次要按钮是淡墨「水洗」底，不用描边框。
- 输入框为淡墨填充 + 大圆角，聚焦时出现一圈浅墨线。
- 底部导航与页面同纸，向上淡出；选中项是一团淡墨胶囊。

## 关键交互

- 卡片轮盘：卡片高度固定，只做绘制层的缩放、轻微翻转、渐淡与虚化；轻划一下就到下一张，弹簧缓停；鼠标滚轮一格一张；高度变化时不会停在两张中间。
- 时间选择：日期 / 时 / 分三列循环滚轮，过去的时刻（或记录睡眠时的未来时刻）显示为删除线淡墨，选中会自动挪回可用范围；鼠标需在滚轮上停留片刻后，滚轮才会转动，避免滚动页面时误改。
- 课表：点空白处安排一小时，长按后拖动圈出一段；已过去的时段淡化且不可点。
- Windows：无原生标题栏，纸面标题栏含「桌面挂件 / 置顶 / 最小化 / 最大化 / 关闭」；挂件模式为置顶小窗，可调透明度，位置与大小会记住。


## 1.1.0+3 信息层级

首页以此刻时钟为主体，七日选择压缩成一行，今天用文字/描边标记、选中日用墨底标记。专注时收起日期条，倒计时与执行操作单独成面板。手机一周页默认整周时间占用总览，选日后看文字明细；详细课表仍可切换。任务操作在卡片菜单和统一详情中保持一致。

## 周视图配色（2026-10-20 修订）

墨晕形色块被反馈为「脏」，已撤下。现在每段安排是一块小圆角平涂浅底（浅色纸 14%、夜墨 22%），左侧一道 3px 实色细线标明是哪件事，文字一律用焦墨。颜色只承担区分，不参与氛围：朱砂、石青、石绿、藤黄、胭脂、靛蓝、赭石、黛青（`theme/schedule_ink.dart`），按任务创建顺序稳定分配；没有待办的保护时段用重墨灰。宣传页 `site/index.html` 使用同一组色值。
