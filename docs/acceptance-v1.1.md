## 本轮查出并修复

- 服务端生成实体 ID 时，新建/专注回执可能遗漏。
- 新建回执排队后改名、改期，专注回执排队后续时，日终提问排队后已提交原文：旧消息应失效。
- 等待任务重新打开后，公众号及手机不得再发旧检查点提醒。
- 15 秒测试通知在途中同步时被误取消；现在保留到展示窗口结束，关闭提醒时仍立即撤销。
- 小屏键盘导致首页轮盘负高度、周页面和空态溢出；已覆盖三个编辑删除入口。
- 专注中的删除入口原先只能返回“先结束”错误；现在在明确确认后结束投入，再撤下待办。
- 新建 UI 测试依赖运行时钟，跨日后误报时间轴断言；固定测试时钟，保留原断言。
- 用户原话“今天上午12点之前完成这个项目的开发”：11:10:35 生成、11:13:35 确认，截止仍为 12:00，仍保留原估时与验收标准，不伪造完成。

## 打包前仍需补足的真实证据

1. **真实模型**：用当前配置的服务复核截止安排、迟到、部分完成、等待结果和材料复盘。替身测试能证明操作可执行，不能证明真实模型理解正确。
2. **正式公众号**：实际收到新建、专注和到点问询，再回复完成/续时；接口与模板投递状态必须留证。模拟服务通过不代表微信已送达。
3. **OPPO**：通知权限、准时提醒、锁屏、划走、重启及删除/续时后的旧提醒撤销。安装包生成前可完成代码和驱动验证，系统实际展示只能在设备运行开发版后验收。

当前开发宿主的 AppData 指向包缓存，与运行中的 1.0.0+2 后台不同，缓存凭证认证失败；不能用该目录替换正式数据。后续真实模型/公众号验收需要在正常数据环境进行。不得为了通过测试而清空配置、重新配对或复用真实任务作测试数据。

更早设计中的回忆卡片、间隔复习、目录级不外发、托盘、自启和备份恢复仍在独立待办中，不因本轮九项源码复核而标为完成。
